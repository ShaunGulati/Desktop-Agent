# CAPRI

A desktop pet for macOS that sees what is on your screen, answers questions about it with
local models, and hands bigger multi-step tasks to an agent with its own sandboxed browser.
The full design lives in the [design doc](https://claude.ai/artifact/WJCGYSQU5ra6H7WoGMF1NT).

**Status:** milestone M0 (foundations): a floating pet window, a global hotkey, the Swift
bridge, the skin system, tests and CI. No model or agent features yet.

## Requirements

- macOS 13 or later on Apple Silicon
- Xcode 16 or later (Swift 6 toolchain)
- Rust (stable), Node.js 22, pnpm

## Run it

```sh
pnpm install
pnpm tauri dev
```

The pet appears in the bottom-right corner of your screen.

| Action | How |
| --- | --- |
| Show or hide the pet | `⌥ Space` (Option+Space), or the CAPRI menu-bar icon |
| Move the pet | Drag it |
| Preview every animation (dev builds only) | Right-click the pet to cycle through states |
| Quit | CAPRI menu-bar icon → Quit CAPRI |

CAPRI runs as an accessory app, so it has no Dock icon. The terminal running `pnpm tauri dev`
logs the hotkey-to-first-paint latency for each show, measured against the 100 ms M0 budget.

## Test it

```sh
pnpm verify          # everything CI runs
pnpm verify:web      # svelte-check + vitest
pnpm verify:swift    # Swift bridge tests
pnpm verify:rust     # rustfmt, clippy, cargo test
```

## Layout

| Path | What lives there |
| --- | --- |
| `src/` | Svelte 5 pet UI (SvelteKit in SPA mode) |
| `src/lib/skin/` | Skin manifest parsing, animation timing, sprite player |
| `src-tauri/` | Rust core (Tauri 2): pet window, hotkey, tray, FFI wrappers |
| `swift/CapriBridge/` | Swift package exposing macOS APIs to Rust over a C ABI |
| `static/skins/default/` | Placeholder skin (generated by `scripts/generate_placeholder_skin.py`) |

## Skins

A skin is a folder of PNG sprite strips, one per pet state, plus a `skin.json`:

```
skin.json
idle.png  listening.png  thinking.png  talking.png
working.png  waiting.png  sleeping.png  error.png
```

Each PNG is a horizontal strip of equal-size frames. `skin.json` sets the frame size and,
per state, the frame count, `fps` (default 8) and `loop` (default true):

```json
{
  "name": "Default blob",
  "frame": { "width": 64, "height": 64 },
  "scale": "pixelated",
  "states": {
    "idle": { "frames": 8, "fps": 6 },
    "thinking": { "frames": 6, "fps": 8 }
  }
}
```

Only `idle` is required: any state a skin leaves out falls back to `idle`. Misspelled state
names are reported as errors. Use `"scale": "smooth"` for drawn (non-pixel) art.

Loading skins from `~/Library/Application Support/` is planned; for now, replace the files
in `static/skins/default/` to try your own art.
